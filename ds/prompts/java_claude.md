# Java-датасет через другой чат Claude — по своим практикам

## Как пользоваться
1. Новый чат Claude → прикрепить файлы практик (.java, задание .pdf/.docx/.md) → вставить ПРОМПТ ниже.
2. Claude отвечает одним блоком `EXAMPLES = [...]` → кнопка Copy на блоке.
3. В терминале: `cd ~/Developer/coder/ds && ./ds.sh paste java` — проверка (javac + запуск) и запись,
   годные коммитятся сами; для плохих в буфере появится «исправь» → вставить в тот же чат.
4. Следующая порция: написать в чат «ещё» (или вставить ПРОДОЛЖЕНИЕ). Через ~5 порций — новый чат.

Цель категории `java`: ~70 примеров (`./ds.sh status`).

````

ШАГ 2: примеры. В каждой порции 6 примеров, смешанных по видам:

  логическая часть до ~120 строк), вопрос «объясни, как устроена и работает программа». Ответ —

- gotcha / output (2): неочевидное поведение Java на темах практик: == vs equals, кэш Integer

  equals/hashCode в HashSet/HashMap, перегрузка vs переопределение, static vs instance, return в finally,
  Arrays.asList, порядок инициализации, generics и стирание типов, Comparator, record, switch.
- write (1): похожая на практику задача «напиши …» с полным решением.
- compare (иногда): два способа решить одно и то же (цикл vs stream, ArrayList vs LinkedList…).

ТРЕБОВАНИЯ К КОДУ (его скомпилируют javac и запустят java — иначе пример выбрасывается):
- Один файл. Ровно один `public class Main` с `public static void main(String[] args)`; остальные классы и
  интерфейсы — в том же файле без `public`. Без `package`. Только стандартная библиотека.
- Детерминированно: без Random без seed, без времени, без порядка HashMap/HashSet в выводе (если
  порядок важен — TreeMap/LinkedHashMap или сортировка). Что-то печатает в System.out.
- Ввод с клавиатуры (Scanner) — только если добавишь поле stdin="строки ввода\n".
- Если код из практики не собирается в один файл как есть — адаптируй минимально (убери package,
  сделай классы не public, замени чтение файла на строку в коде) и скажи об этом в ответе одной фразой.
- Если можешь выполнять код — ОБЯЗАТЕЛЬНО запусти каждый пример и пиши по РЕАЛЬНОМУ выводу. Если не
  можешь — проследи выполнение очень внимательно: мой скрипт сверит вывод из ответа с настоящим.

- Жирные мини-заголовки: **Механизм — <точный термин>**, **Почему так**, **Подвох**,
  **Граничные случаи**, **Как исправить**, **Сложность** (для system — свои, см. выше).
- Точные термины: автоупаковка/распаковка, пул строк, кэш Integer, переполнение, стирание типов,

  «Надеюсь, это поможет», «В заключение». Без LaTeX.
