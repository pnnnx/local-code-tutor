# Датасет «объяснение кода» — всё делается здесь

Папка: `~/Developer/coder/ds`. **Только здесь.** `loca` — это агент, датасета там нет.

```
ds/
  ds.sh              ← единственная команда, которая нужна
  parts/             ← принятые примеры (по темам); gpt_*.jsonl — из ChatGPT
  batches/           ← сырые ответы ChatGPT (сохраняются сами)
  explain_ru_train.jsonl  ← итог для Kaggle (собирается ./ds.sh build)
  tools/             ← проверка, дубликаты, сборка — руками не трогать
  GPT_PROMPT.md      ← справка: сколько просить, сколько надо
```

## Как собирать (самый простой способ)

```bash
cd ~/Developer/coder/ds
./ds.sh
```
Скрипт покажет, чего не хватает, — введите номер темы (или просто Enter). Дальше он ведёт сам:

1. **«Откройте НОВЫЙ чат ChatGPT → Cmd+V»** — промпт уже в буфере, просто вставьте и отправьте.
2. **«Нажмите Copy на блоке кода и вернитесь сюда»** — в ответе ChatGPT кнопка Copy у блока кода,
   потом в терминале **Enter**. Скрипт сам заберёт ответ, запустит код, проверит и запишет годное.
3. **«В буфере — …, вставьте в ТОТ ЖЕ чат»** — там уже лежит следующее сообщение
   («ещё порция» или «исправь вот эти»). Cmd+V в чат → ChatGPT ответил → Copy → Enter.
4. Через ~6 порций скрипт сам скажет открыть **новый** чат.
5. Хватит — **q**.

⚠ Ничего не вставляйте в терминал — только в ChatGPT. В терминале нажимается только Enter.

Когда наберётся сколько нужно:
```bash
./ds.sh build                  # → explain_ru_train.jsonl (повторная проверка + чистка дублей)
```
Этот файл загружаете в Kaggle вместо старого и запускаете ноутбук обучения.

Отдельные шаги, если нужно: `./ds.sh status` · `./ds.sh go py_pandas` · `./ds.sh new|more|paste py_pandas` ·
`./ds.sh add batches/файл.py`.

## Добрать датасет через Claude одним файлом

```bash
./ds.sh claude          # промпт на 60 примеров по 8 самым пустым категориям → в буфер
```
Новый чат Claude → Cmd+V. Claude с выполнением кода соберёт и проверит файл `dataset_batch.py` —
скачайте его и `./ds.sh add ~/Downloads/dataset_batch.py` (категории берутся из примеров, каждая
коммитится отдельно). Без файлов Claude пришлёт блоки — Copy → `./ds.sh paste`.
Каждый новый чат — новый `./ds.sh claude`: промпт пересчитывает, чего не хватает и что уже покрыто.
Java по своим практикам — `./ds.sh java-prompt` (см. `prompts/java_claude.md`).

## Режим «ворчун» (реакции с матом)

```bash
./ds.sh persona          # или в меню ./ds.sh → p
```
Дальше всё как обычно: Cmd+V в ChatGPT → Copy → Enter. ChatGPT пишет только короткие реакции
(«бля, кожаный, опять мутабельный дефолт… ладно, смотри») и диалоги «всё равно не понял» —
объяснение берётся из уже проверенного примера. Свой стиль — в `persona_style.txt` (по фразе на строку).
Цель — ~300. Режим включается строкой в системном промпте: в loca это `/grumpy` или `loca --grumpy`,
без неё модель отвечает как обычно (это проверяет ячейка 8b ноутбука обучения).

## Категории
`./ds.sh status` покажет все. Начинать с самых пустых: `py_pandas`, `sql_analytics`, `py_dashboards`,
`py_systems`, `py_bugs`, `java`, `ml_weights`. Цель — ~2330 примеров всего.

ML: **`ml_weights`** — анализ весов и моделей (state_dict, статистика по слоям, сравнение
чекпоинтов до/после дообучения, LoRA и SVD, квантование и его ошибка, активации и внимание
через hooks, градиенты, эмбеддинги, абляции, кривые обучения); `ml_pytorch` — тензоры, autograd,
цикл обучения и его баги; `ml_classic` — numpy, scikit-learn, метрики. Для проверки:
`pip3 install torch numpy scikit-learn safetensors matplotlib` — всё на CPU за секунды.

## Что проверяется автоматически
Код каждого примера реально запускается; ответ должен совпадать с настоящим выводом;
исключение должно быть названо; **дубликаты** (тот же код с другими именами) отклоняются —
и против всего датасета, и внутри одного ответа; копии контрольных вопросов отклоняются;
ответ — на русском, нормальной длины, без «воды». Номера примеров ставятся сами.

## Что нужно на Mac
`python3` есть. Для проверки JS — `brew install node`, Java — `brew install openjdk`,
C/C++ — Xcode Command Line Tools (уже стоят). pandas/графики: `pip3 install pandas matplotlib seaborn plotly streamlit`.

## Частые ошибки
- `can't open file .../tools/build.py` — вы не в папке `ds`: `cd ~/Developer/coder/ds`.
- «В буфере нет EXAMPLES» — скопирован не блок кода, а текст ответа. Жмите Copy именно на блоке.
- «Файл не разбирается как Python» — ChatGPT оборвал ответ на середине: попросите «продолжи/пришли целиком» или уменьшите порцию: `./ds.sh more py_pandas 4`.
