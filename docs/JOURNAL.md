## 2026-10-20 — этап 4: инструменты анализа весов с графиками (wtools)
**Что:** `wtools/weights.py` — `inspect` (тензоры, память fp32…int4, крупнейшие блоки), `stats` (RMS/|max|,
выбросы > 6σ, нулевые строки, разреженность, гистограмма), `diff` (‖ΔW‖, ‖ΔW‖/‖W‖, косинус по слоям и типам
модулей), `lora` (ΔW = B·A·alpha/r: норма, эффективный ранг, доля σ₁², спектр), `quant` (ошибка int8/int4:
на тензор / строку / блок 32). Каждый — таблица со всеми числами с графика + PNG. `wtools/mcp_server.py` —
те же 5 инструментов для loca по MCP; `install_loca.py` прописывает сервер в `~/.loca/config.json`.
**Как:** torch + safetensors + matplotlib (loca остаётся на stdlib — инструменты живут в отдельном процессе).
Сингулярные числа LoRA — через QR (r×r вместо out×in), поэтому быстро и для 7B. Порядок слоёв
естественный (L2 < L10), ось — номера слоёв, на графике подписан максимум. Палитра и оформление — по
правилам dataviz (одна ось, фиксированный порядок цветов, легенда только при ≥ 2 рядах).
**Зачем:** главное желание — копаться в нейронке с графиками и не в одиночку: модель вызывает инструмент
и объясняет график по числам (графики она не видит, поэтому числа — в тексте).
**Проверка:** 6 тестов `wtools/test_weights.py` (выброс и мёртвая строка находятся; топ изменившихся слоёв;
